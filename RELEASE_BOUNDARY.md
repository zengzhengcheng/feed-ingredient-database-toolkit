# Release boundary

- Public software release: `v1.0.1`
- Code license: MIT
- Repository visibility: public

This repository contains software, tests, editable read-only SQL query rules, blank contribution templates, seed dictionaries, and reproducible reuse examples. The formal 110 public workbooks, exchange tables, data dictionaries, and release SQLite database are data products distributed separately through ScienceDB under DOI [10.57760/sciencedb.46393](https://doi.org/10.57760/sciencedb.46393).

That DOI currently identifies the published V3 dataset. The October 2026 reviewer-revision data candidate remains local and is not represented as already public by this software release.

Excluded here: the 110 formal workbooks, the formal release SQLite database, ScienceDB exchange tables, source article PDFs/full text, user working databases, diet/formulation data, and the complete ScienceDB data package.

Related article or project: Not applicable.
