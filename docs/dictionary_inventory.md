# 初始名称词典清单

本词典来自旧系统已经使用过的名称对照，不是根据当前数据重新做的词频库。

## 来源与内容

| 来源 | 原料名称 | 指标名称 | 动物种类 | 合计 |
|---|---:|---:|---:|---:|
| 旧 SQL 名称表与历史名称映射 | 517 | 1,025 | 0 | 1,542 |
| `nameManager/articleNameDict.py` | 7 | 210 | 6 | 223 |
| 初始历史名称映射合计 | 524 | 1,235 | 6 | 1,765 |

此外，程序内置 3 个基础/干湿物质写法和 3 个常用单位作为录入辅助项。

旧 SQL 的 1,025 个指标名称按测量语境分为：普通成分 424、能量 30、AID 184、SID 191、ATTD 190、STTD 6。旧 Python 源码补充的 210 个指标名称按相同方式保存。

## 典型作用

```text
sbm -> soybean meal
yellow corn -> Corn
Crude Protein -> CP
crude protrin -> CP
metabolism energy -> ME
ame -> AME
Lys（AID/SID 语境）-> Lysine
```

这些映射主要解决：

- 同一原料的缩写、全称和旧写法；
- 大小写、空格和常见拼写错误；
- 同一营养指标的缩写和全称；
- AID、SID、ATTD、STTD 等不同语境下容易混淆的指标；
- 旧系统已有写法与当前统一名称的兼容。

## 不属于词典的工作

- 不根据出现频次决定名称是否正确；
- 不判断数值是否合法；
- 不决定原料和动物组关系是否完整；
- 不把未收录名称自动判为错误数据。

数值、单位、基础、动物关系和必填项由录入校验负责。词典只负责名称识别、纠错提示和统一命名。
