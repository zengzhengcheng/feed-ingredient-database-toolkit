# 名称词典说明

## 一句话解释

名称词典就是一张“别名对照表”：把 Excel 或论文中的原写法，对应到数据库中的统一名称。

例如：

```text
yellow corn -> Corn
Crude Protein -> CP
crude protrin -> CP
```

词典不修改原始数据。数据库同时保存原写法和统一名称，因此任何映射都可检查、可修改。

## 为什么指标还要分语境

同一指标名在不同数据部分可能含义不同。普通粗蛋白含量属于 `composition`；粗蛋白的表观回肠消化率属于 `AID`；标准回肠消化率属于 `SID`。所以指标词典使用“别名 + 语境”共同查找，避免把不同测量含义混在一起。

常用语境：

- `composition`：原料自身成分；
- `energy`：能量值；
- `AID`、`SID`：回肠消化率；
- `ATTD`、`STTD`：全肠道消化率；
- `CATTD` 等：原历史数据中有明确名称的其他类型，保留其原语境。

## 三种状态

- `approved`：管理员确认可使用；
- `candidate`：新出现的写法，数值有效，但名称尚待确认；
- `deprecated`：旧映射保留用于追溯，不建议继续使用。

`candidate` 不等于 `held`。前者只是“名字还没统一”，后者才表示数据结构或解释存在问题。

词典不需要做词频统计。名称出现一次还是一百次，都不能决定它是正确术语、别名还是拼写错误。判断依据是名称含义和测量语境。

## 录入界面的即时检查

点击“检查当前记录”或保存时，界面会：

1. 检查 DOI、必填关系、数值、单位、基础和动物信息；
2. 已知别名直接显示其统一名称；
3. 未收录但与旧词相似时提示可能的拼写错误；
4. 确认确为新名称后，将它作为新的 `approved` 规范名称加入词典；
5. 如果其实是别名，在词典页把它对应到已有规范名称。

只有无法交互确认的历史批量导入和外部 Excel 导入，才暂时把新名称记为 `candidate`。

## PyQt6 中怎样处理新词

1. 打开“管理名称词典”；
2. 选择类别；
3. 指标类别需要选择语境；
4. 填写原写法和统一名称；
5. 确认后设为 `approved` 并保存。

保存后，已入库的相同原写法会立即更新统一名称，不必重新导入 Excel。建议只确认自己能够判断的别名；不确定时继续保留为 `candidate`。
